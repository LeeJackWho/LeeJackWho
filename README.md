## 📝 最近在折腾什么

- **UI 自动化的稳定性**：元素定位漂移、异步握手竞态、失败自动取证——把"本地绿、CI 红"的问题逐个拆掉
- **设备模拟测试**：在设备到现场之前，用一条 MQTT 消息链路验证整套上报协议（连接 / 回路 / QoS / 遗留消息 / 通配符）
- **AI + 测试**：探索视觉模型定位元素、Agent 自动执行用例的可行边界
